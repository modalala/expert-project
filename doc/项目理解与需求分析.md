# 专家库管理系统 - 项目理解与需求分析

## 项目概述

这是一个全新的专家库管理系统，用于管理招投标过程中的专家资源，包括专家注册、审核、抽取、评标、评分等全流程管理。

## 技术栈确认

| 层级 | 技术选型 |
|------|----------|
| 前端 | Vue3 + Composition API |
| 后端 | Spring Boot |
| 数据库 | MySQL |
| 部署环境 | 内网服务器 |

## 已有基础设施

- 企业微信集成：已有，可直接使用
- 短信服务：需新建
- 郵件服务：需新建
- 用户体系：需新建
- UI设计稿：无，自行设计

## 功能模块清单（按开发优先级）

### 第一阶段：专家库核心（优先开发）

| 模块 | 功能 | 预估人天 |
|------|------|----------|
| 公开征集专家 | 门户新增专家注册入口、注册页面（基本信息、职业证书、教育经历、成果展示）、附件上传 | 3 |
| 内部推荐专家 | 内部专家注册、用户数据关联、模版配置、附件上传 | 2.5 |
| 专家初审 | 初审菜单、权限控制、状态控制、消息通知配置 | 2 |
| 专家复审(OA审批) | 内部审批流程、审批结果处理、账号自动生成、消息通知 | 1.5 |
| 专家主数据 | 批量导入导出、状态变更管理 | 1.5 |
| 用户体系 | 用户注册、登录、权限管理、角色管理 | 2 |

**第一阶段合计：约12人天**

### 第二阶段：业务流程

| 模块 | 功能 | 预估人天 |
|------|------|----------|
| 采购方案单 | 新建采购方案模块、抽取方案配置（线上/线下） | 1 |
| 专家抽取方案 | 收取方案设置、多维度抽取规则、排除条件 | 1.5 |
| 专家确认流程 | 邮件/企微通知、单点登录确认页面、同意/拒绝处理、自动补抽 | 2 |
| 评标委员会 | 线上/线下抽取专家生成委员会信息、开标前后信息展示控制 | 1 |
| 专家评分 | 评分权限控制、评分页面、扣分记录、违规一票否决 | 2 |
| 专家画像 | 抽中次数统计、评标记录、评分得分展示 | 1 |

**第二阶段合计：约8.5人天**

### 第三阶段：完善与优化

| 模块 | 功能 | 预估人天 |
|------|------|----------|
| 实施方案同步 | 实施单与方案单同步 | 0.5 |
| 专家补抽 | 开标前补抽专家、手动选择专家库专家 | 0.5 |
| 消息通知完善 | 短信服务集成、邮件服务集成 | 1 |
| 测试与调优 | 功能测试、性能优化、Bug修复 | 2 |

**第三阶段合计：约4人天**

**总预估：约24.5人天**（原清单估算18人天，重新评估后考虑新增用户体系、采购方案单等模块）

## 需要自行设计的内容

- 专家类型分类（如：技术类、经济类、法律类等）
- 专家级别分类（如：初级、中级、高级、资深）
- 擅长领域分类（根据业务领域划分）
- 专家状态定义（潜在专家、正式专家、暂停专家、淘汰专家等）
- 评分指标体系（迟到、缺席、违规行为等扣分项）
- 一票否决条件（重大违规定义）
- 拒绝原因选项列表

## 待确认事项

1. 采购方案单、实施单的具体业务流程和数据结构需要进一步讨论
2. 专家抽取的详细规则算法（如何实现随机抽取、排除条件逻辑）
3. 单点登录的具体实现方式（企微链接如何实现免登录）
4. 内网服务器是否有具体的部署要求（端口、域名、SSL证书等）
